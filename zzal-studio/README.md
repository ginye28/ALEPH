# 짤·카드 스튜디오

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 내려받는 제작 도구입니다.
설계 근거는 [../짤카드-스튜디오-설계도.md](../짤카드-스튜디오-설계도.md)에 있습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # dist/
npm run lint
```

## 구조

| 경로 | 역할 |
|------|------|
| `src/render/composition.js` | **단 하나의 그리기 함수.** 미리보기와 내보내기가 함께 씁니다 |
| `src/render/textLayout.js` | grapheme 단위 줄바꿈 + 넘칠 때 자동 축소 |
| `src/render/ratios.js` | 1:1(1080×1080) · 4:5(1080×1350) · 9:16(1080×1920) |
| `src/storage/schema.js` | 템플릿 검증. 하나라도 실패하면 저장하지 않습니다 |
| `src/storage/templates.js` | localStorage CRUD. 모든 변경 뒤 저장소에서 다시 읽습니다 |
| `src/utils/loadImage.js` | PNG·JPEG 검증, 15MB 상한, 실패해도 기존 상태 유지 |
| `src/utils/download.js` | 내보내기 6단계 (글꼴 대기 → 렌더 → toBlob → 크기 0 검사 → 저장) |

## 검사 자료

`검사 자료/` 폴더에 카드 5 검증용 파일이 있습니다.

| 파일 | 넣었을 때 기대 결과 |
|------|--------------------|
| `정상.json` | 템플릿 3개가 이름·설정 그대로 복원 |
| `문법오류.json` | "파일 형식이 올바르지 않습니다. (JSON 문법 오류)" · 기존 목록 유지 |
| `필수항목누락.json` | "2번째 템플릿의 필수 항목이 빠졌습니다. (화면비)" · 기존 목록 유지 |

## 설계 원칙 세 가지

1. **좌표는 전부 0~1 정규화로 저장합니다.** 픽셀은 그리는 순간에만 만듭니다.
2. **그리는 코드는 `renderComposition()` 하나뿐입니다.** 미리보기 캔버스도 출력 해상도(1080px 기준)로
   그린 뒤 CSS로만 줄여 보여주므로, 미리보기와 내려받은 파일의 배치가 다를 수 없습니다.
3. **저장은 "전부 검증 → 통째로 교체"만 합니다.** 잘못된 파일을 넣어도 기존 템플릿과 편집 내용이 남습니다.

## 개인정보

- 서버가 없습니다. 이미지·문구·템플릿이 브라우저 밖으로 나가지 않습니다.
- 캔버스에 다시 그려 인코딩하므로 내려받은 파일에 원본의 EXIF·GPS 정보가 남지 않습니다.
- 템플릿에는 배치 설정만 담기고 이미지 파일은 저장하지 않습니다.
