03 — My Strengths

01

문제가 생기면 원인을 찾는다

상황

학원 팀 프로젝트에서 소셜 로그인 기능을 구현하던 중 특정 로그인 과정에서 오류가 발생했다.

행동

오류 메시지와 로그인 데이터를 확인하면서 전달되는 값의 타입과 데이터베이스 구조를 비교했다.

결과

원인을 찾아 데이터 타입을 수정했고 해당 로그인 과정이 정상적으로 동작하도록 해결했다.

오류 메시지만 확인하는 데 그치지 않고, 전달되는 데이터와 데이터베이스 구조를 비교하면서 원인을 좁혀갔습니다. 문제를 단순히 수정하는 것보다 왜 발생했는지 확인하는 과정에 집중했습니다.
