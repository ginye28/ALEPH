**<https://aleph-passkey.vercel.app>**

만들지 않습니다. "막았습니다"라고 적는 대신 **막히는 장면**(성공 요청과 거절 요청을

## 비밀번호가 없습니다

등록할 때 **기기가 열쇠 한 쌍을 만들어 공개키만 서버로 보냅니다.** 서명을 만드는 개인키는
기기(지문 센서·Face ID·보안 키) 밖으로 나가지 않습니다. 로그인할 때는 서버가 **매번 새
질문(challenge)** 을 보내고, 기기가 그 질문에 개인키로 서명해 답합니다. 서버는 저장해 둔
공개키로 그 서명을 확인한 뒤에만 통과시킵니다.

화면 어디에도, 소스 어디에도 비밀번호를 입력하는 칸이 없습니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

개발 서버는 <http://localhost:5179> 에 열립니다. `localhost`는 WebAuthn이 HTTPS 없이도
허용하는 유일한 예외라 인증서 없이 개발할 수 있습니다.

`tools/dev-server.mjs`는 Vercel의 라우팅 규칙(`api/a/b.js` → `/api/a/b`,
`api/a/[id].js` → `/api/a/무엇이든`)만 흉내 내는 얇은 서버입니다. **핸들러 파일은 로컬과
배포가 완전히 같은 코드**라, 로컬에서 통과한 것이 배포에서도 같은 코드로 통과합니다.

Supabase 환경변수가 없으면 `.dev-store/store.json` 파일 하나를 저장소로 씁니다.
실제 배포에는 아래 두 개가 필요합니다(둘 다 **서버에만** 두고 브라우저로 내려보내지
않습니다):

```
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
```

스키마는 `supabase/schema.sql`을 Supabase SQL 편집기에서 실행하면 만들어집니다.

## 검증 안내서

**어디로 가나요** — 공개 주소 (첫 화면은 누구나 볼 수 있는 소개 페이지)

**세 단계 안에 무엇을 하나요**

1. 맨 아래 **🔒 나만 보는 자리**에서 "패스키 새로 등록하기"를 눌러 지문·얼굴·PIN으로 등록한다.
2. 열린 자리에 메모를 한 줄 남긴다.
3. "로그아웃"을 누르고 같은 자리를 다시 본다.

**무엇이 보이면 통과인가요**

- 1·2단계 뒤 — 배지가 **열림**으로 바뀌고 비공개 항목이 보인다.
- 3단계 뒤 — 다시 **잠김**으로 돌아가고 내용이 사라진다. 페이지 소스를 열어 봐도 없다.

**안 될 때는**

- 패스키를 지원하지 않는 브라우저면 안내 문구가 뜨고 버튼이 꺼진다.
- 등록 도중 지문 창을 닫으면 "등록을 취소했습니다 — 서버에는 계정도 패스키도 만들어지지
  않았습니다"가 뜬다.

## 알아둘 설계 결정

**비밀번호를 하나도 남기지 않았습니다.** 예비 수단으로라도 비밀번호를 두면 잠금의 세기는
가장 약한 곳으로 정해집니다. 그래서 복구 수단 자체를 두지 않았고, 그 대가(마지막 패스키를
잃으면 계정도 잃는다)를 화면과 보고서에 그대로 밝힙니다.

**세션은 서버가 들고 있습니다.** 쿠키에 실리는 값은 `pk_sessions` 행 하나를 가리키는 무작위
id일 뿐, 값 자체에는 아무 정보도 없습니다(JWT가 아닙니다). 로그아웃은 그 행을 지우는
것이고, 지우는 즉시 그 값으로는 아무것도 열리지 않습니다. 과제 7에서 서명된 토큰이
로그아웃 뒤에도 만료 전까지 살아 있던 문제를 나중에 손봐야 했는데, 이번에는 처음부터 그
문제가 생기지 않는 쪽으로 설계했습니다.

**주인은 세션이 정합니다.** 요청 본문에 `user_id`를 적어 보내도 서버는 읽지 않습니다.
자료를 만들 때 쓰는 주인은 언제나 `requireUser()`가 돌려준 값입니다
(`api/private-notes/index.js`). 클라이언트가 주인을 고를 수 있는 경로가 코드에 없습니다.

**남의 자료는 403이 아니라 404로 답합니다.** "있지만 권한이 없다"고 답하면 그 id가
존재한다는 사실 자체를 알려주는 셈입니다. 없는 것과 똑같이 답합니다.

**브라우저는 DB에 직접 닿지 않습니다.** Supabase URL도 키도 브라우저로 내려보내지
않습니다. 모든 접근은 `/api` 서버리스 함수가 `lib/store.js`를 통해서만 합니다.
