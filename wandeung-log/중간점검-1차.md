# 중간 점검 1차 — 제출 폼 붙여넣기용 초안

> 아래는 초안입니다. 특히 **"AI에게 맡긴 일과 내가 판단한 일"** 항목은
> 본인이 실제로 판단한 내용으로 고쳐 쓰세요. 그대로 내면 안 됩니다.

## 이번에 만든 것

완등 기록 웹앱의 전체 화면 4개를 만들었습니다.

1. **기록** — 날짜 → 암장 → 난이도 → 결과의 4단계로 입력합니다. 난이도는 홀드처럼 생긴 컬러 칩 10개,
   완등/실패는 큰 버튼 두 개입니다. 같은 날 같은 암장 기록은 하나의 세션으로 묶여,
   세션마다 "5건 · 완등 4 · 완등률 80%"가 표시됩니다.
2. **성장 그래프** — 지표 카드 4장(전월 대비 상승/하강 표시), 월별 완등률 꺾은선,
   월별 기록 수 누적 막대(완등/실패), 난이도별 완등/실패 가로 막대, 월별 집계표.
   그래프는 마우스를 올리면 수치가 뜹니다.
3. **팁 게시판** — 암장·난이도를 붙여 팁을 올리고 암장별로 거를 수 있습니다.
4. **난이도 안내** — 웨이브락 색상 단계표(Lv.1~10)와 용어 정의, 그리고 참고용 V등급 ↔ Font 등급 대응표.

화면 오른쪽 위 해/달 버튼으로 라이트·다크를 바꿀 수 있고(기본 다크), 선택은 저장됩니다.

실제 동작: 기록을 저장하면 브라우저에 남고, 다시 열어도 그대로 있습니다.
기록이 하나도 없을 때는 예시 데이터가 보이고, 첫 기록을 저장하면 예시는 사라집니다.

## 확인하는 방법 · 3단계 이내

1. 결과물 URL에 접속합니다.
2. **기록** 탭에서 날짜·암장·난이도·결과를 골라 서로 다른 날짜로 5건 이상 저장합니다.
3. **성장 그래프** 탭에서 월별 완등률 곡선과 난이도별 막대가 그려지는지 확인합니다.

## 바뀐 점과 그 이유

- **사진·영상 업로드를 넣지 않기로 확정했습니다.** 완성 기준이 "영상/사진 없이"였고,
  입력이 무거워지면 암장에서 그 자리에 기록하지 않게 되기 때문입니다.
- **난이도를 색상 + V등급 두 가지로 같이 보여주도록 바꿨습니다.**
  국내 암장은 색으로 부르는데 암장마다 색 순서가 달라서, 색만 쓰면 그래프의 x축이 암장을 옮기는 순간 뜻을 잃습니다.
  공통 눈금(V등급)을 같이 두고 기록에 암장 이름을 붙이는 방식으로 정리했습니다.
- **UI를 스포츠 앱 방식으로 전면 리디자인했습니다.**
  처음 버전은 입력칸이 줄줄이 선 폼이라, 암장에서 땀 흘리며 쓰기에는 손이 많이 갔습니다.
  기록을 안 남기면 그래프도 의미가 없으니 입력을 동작으로 바꿨습니다.
  날짜 → 암장 → 난이도 → 결과 4단계로 나누고, 난이도는 실물 홀드처럼 생긴 컬러 칩 10개,
  완등/실패는 큰 터치 버튼 두 개로 만들었습니다. React + Tailwind + Lucide로 다시 썼습니다.
- **라이트/다크 테마 토글을 넣었습니다.** 기본은 다크이고 선택은 저장됩니다.
- **차트가 테마를 따라오지 않던 버그를 고쳤습니다.**
  색을 자바스크립트로 읽어 그리다 보니, 테마를 바꾼 직후 한 번은 이전 테마 색이 그대로 남았습니다.
  라이트로 바꿔도 격자선이 어두운 색이라 거의 보이지 않았습니다.
  색을 CSS 변수에 직접 묶어, 테마가 바뀌면 다시 그리지 않아도 따라오게 했습니다.
- **좁은 화면에서 그래프 축 글자가 같이 줄어들던 문제를 고쳤습니다.**
  그래프를 고정 폭으로 그린 뒤 화면에 맞춰 축소하니, 휴대폰에서 축 숫자가 5px까지 작아졌습니다.
  컨테이너 실측 폭을 그대로 그림 폭으로 쓰도록 바꿔 어느 폭에서도 글자 크기가 같습니다.
- **난이도 순서를 다니는 암장(웨이브락) 기준으로 바꿨습니다.**
  처음에는 흰색이 가장 쉬운 순서로 잡았는데, 실제로는 빨강이 가장 쉽고 흰색이 가장 어렵습니다.
  순서가 틀리면 "성장 그래프"의 난이도 축이 거꾸로 서기 때문에 눈금부터 고쳤습니다.
- **색상 단계에 붙어 있던 V등급 표기를 뺐습니다.**
  어떤 색이 몇 V인지는 암장과 세팅마다 달라서, 임의로 붙이면 틀린 정보가 됩니다.
  색은 Lv.1~Lv.10 단계로만 표시하고, V등급 ↔ Font 등급은 국제 기준 참고표로 따로 두었습니다.
- **자주 가는 지점을 버튼으로 골라 넣도록 바꿨습니다.** 매번 암장 이름을 타이핑하면
  "웨이브락 남천"과 "웨이브락 남천점"처럼 표기가 갈려 통계가 두 갈래로 쪼개집니다.
  웨이브락 부산 3개 지점(남천점·서면점·부산대점)을 기본 버튼으로 넣고, 그 외 암장은 직접 입력하면 목록에 남게 했습니다.
- **방문 횟수를 "기록 건수"가 아니라 "날짜+암장 묶음"으로 세도록 바꿨습니다.**
  하루에 5건을 적어도 방문은 1회여야 완성 기준의 "2회 이상 방문"이 제대로 판정됩니다.
- **월별 완등률과 월별 기록 수를 한 그래프에 겹치지 않고 두 개로 분리했습니다.**
  축이 둘인 그래프(%와 건수)는 읽는 사람이 항상 잘못 읽습니다.

## AI에게 맡긴 일과 내가 판단한 일

**AI가 만든 부분**
- React 컴포넌트 구조와 Tailwind 스타일링, SVG 그래프 그리는 로직, 화면 레이아웃과 배색
- 완등/실패 두 색의 색맹 판별 검사와, 검사를 통과하는 조합 찾기
- 완등률·방문 횟수·난이도별 집계를 계산하는 함수
- 게시판의 공유 저장 연결과, 연결 실패 시 로컬 저장으로 내려가는 처리

**내가 검토·수정·결정한 부분**
- (직접 채우기) 기능 3가지의 우선순위와, 이번 버전에서 뺄 것의 결정
- (직접 채우기) 난이도를 색상으로 할지 V등급으로 할지, 둘 다 보여줄지의 판단
- (직접 채우기) 방문 횟수의 정의를 "날짜+암장"으로 잡은 이유 확인
- (직접 채우기) 실제로 기록을 넣어 보고 고친 점
- (직접 채우기) 스포츠 앱 방향으로 리디자인하기로 한 판단과, 기본 테마를 다크로 정한 이유
