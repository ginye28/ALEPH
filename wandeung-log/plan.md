# 완등 로그 — 계획 설계서 v1

작성일: 2026-09-29

## 1. 한 줄 소개

클라이밍 완등 기록 웹앱.

## 2. 누구를 위한 것인가

주 2~3회 이상 암장을 방문하여 난이도별 완등 기록을 남기고 싶은 클라이머.

구체적으로는, 매번 "오늘 몇 개 풀었지?"를 머릿속으로만 세고 넘어가는 사람.
영상이나 사진을 찍어 올리는 건 번거로워서 안 하지만, 자기가 늘고 있는지는 알고 싶은 사람이다.

## 3. 핵심 기능 3가지

### (1) 방문 암장 및 난이도별 완등/실패 기록
- 날짜, 암장 이름, 난이도(색상 등급), 완등/실패, 시도 횟수, 한 줄 메모를 저장한다.
- 같은 날 같은 암장의 기록은 하나의 **세션**으로 묶어 보여준다. 방문 횟수 = 세션 수.
- 난이도 눈금은 웨이브락 색상 순서(빨·주·노·초·하·남·보·갈·검·흰, 왼쪽이 쉬움)를 따른다.
  V등급과는 연결하지 않는다. 어떤 색이 몇 V인지는 암장·세팅마다 달라서, 잘못 붙이면 그래프가 거짓말을 한다.
  V등급 ↔ Font 등급 대응표는 국제 기준 참고표로 따로 둔다.
- 자주 가는 지점은 버튼 한 번으로 고른다. 기본값은 웨이브락 클라이밍 부산 3개 지점
  (남천점 · 서면점 · 부산대점, 공식 지점안내 기준)이며 남천점이 기본 선택이다.
  그 밖의 암장은 입력칸에 직접 적으면 그대로 저장되고 다음부터 목록에 남는다.
- 영상·사진은 받지 않는다. 입력이 무거워지면 기록 자체를 안 하게 되기 때문.

### (2) 월별 완등 성공률 및 성장 그래프
- 월별 완등률(완등 ÷ 전체 기록) 꺾은선 그래프 — 성장 곡선.
- 월별 기록 수 누적 막대(완등/실패) — 얼마나 꾸준히 다녔는지.
- 난이도별 완등/실패 가로 막대 — 지금 내 벽이 어디인지.
- 같은 데이터를 월별 집계표로도 제공(그래프를 못 읽는 상황 대비).

### (3) 암장별 난이도 정보 및 회원 간 팁 공유 게시판
- 색상 난이도 ↔ V등급 ↔ Font 등급 대응표와 용어 설명(완등/실패/시도/세션).
- 암장·난이도를 붙여 팁을 올리는 게시판. 암장별 필터 제공.
- 완등 영상을 붙여 올릴 수 있다. 주소를 아는 사람은 누구나 재생할 수 있다.

### (+) 완등 영상 (선택)

완성 기준이 "영상/사진 **없이**"이므로 영상은 필수가 아니라 선택 첨부로 둔다.
필수로 만들면 기록 5건을 채우는 일 자체가 무거워져 기준을 거스른다.

- 영상을 붙이면 항상 내 브라우저(IndexedDB)에 사본이 남는다 — 나만 본다.
- "게시판에 공유"를 켰을 때만 공유 저장소(Vercel Blob)에 올라가 남이 볼 수 있다.
- 내 사본을 먼저 만들고 업로드를 나중에 한다. 업로드가 실패해도 기록에는 영상이 남는다.

## 4. 완성의 기준

2회 이상 방문하여, 영상/사진 없이 난이도 및 완등 여부 기록 5건 이상 등록 및 그래프 확인.

구체적 판정 조건:
- 서로 다른 세션(날짜+암장) 2개 이상
- 기록 5건 이상, 각 기록에 난이도와 완등 여부가 들어 있을 것
- 성장 그래프 탭에서 월별 완등률 곡선이 그려질 것

## 5. 만드는 방법

- 앱은 `index.html` 한 파일. React 18 + Tailwind CSS + Lucide 아이콘을 CDN에서 불러 쓰고
  빌드 도구는 두지 않는다. 서버는 Vercel 서버리스 함수 두 개(`api/feed`, `api/upload`)뿐이다.
- 완등 기록은 브라우저 `localStorage`에 저장 → 로그인 없이 바로 쓰고, 기록이 남에게 넘어가지 않는다.
- 팁 게시판과 공유 영상만 서버(Vercel Blob)를 쓴다. 글 하나가 파일 하나라 동시에 써도 서로 덮어쓰지 않는다.
- 앱이 뜰 때 `api/feed`를 한 번 찔러 보고 응답이 없으면 로컬 모드로 내려간다.
  그래서 서버가 없는 GitHub Pages·아티팩트에서도 화면이 깨지지 않는다.
- 영상 파일은 서버리스 함수를 거치지 않는다. 함수 본문 한도가 4.5MB라 영상이 통과하지 못하므로,
  서버는 허가 토큰만 주고 브라우저가 저장소로 직접 올린다. 저장소 쓰기 토큰은 서버에만 남는다.
- 그래프는 차트 라이브러리 없이 SVG로 직접 그린다. 컨테이너 실측 폭을 그림 폭으로 써서
  화면이 좁아져도 축 글자가 같이 작아지지 않게 한다.
- 차트 색은 CSS 변수에 직접 묶는다. 테마를 바꾸면 자바스크립트가 다시 읽지 않아도 색이 따라온다.
- 완등/실패 두 색은 라이트·다크 각각 색맹 판별 검사를 통과한 조합만 쓴다.
  라임 계열끼리 두면 적록색약에서 구분이 안 돼(ΔE 1~3) 실패 쪽을 파랑으로 잡았다.

## 5-1. 디자인 방향

스포츠·피트니스 앱(러닝, 트레이닝 기록 앱)의 문법을 따른다. 기록이 귀찮으면 안 남기게 되므로,
입력을 폼이 아니라 동작으로 만든다.

- **테마**: 기본 다크. 헤더의 해/달 버튼으로 라이트와 전환하고 선택은 저장된다.
  다크는 안트라사이트 바탕 + 일렉트릭 라임 액센트, 라이트는 오프화이트 + 잉크 블랙.
- **타이포**: 숫자 지표는 Archivo 900, 본문은 Gothic A1. 완등률·방문 횟수가 화면에서 가장 큰 글자다.
- **난이도**: 드롭다운이 아니라 실물 홀드처럼 생긴 입체 컬러 칩 10개. 색을 눈으로 찾아 누른다.
- **기록 추가**: 날짜 → 암장 → 난이도 → 결과의 4단계. 완등/실패는 큰 터치 버튼 두 개.
- **통계 카드**: 지표마다 아이콘과 전월 대비 상승/하강 인디케이터를 붙인다.

## 6. 이번 버전에서 하지 않은 것

- 로그인 / 여러 기기 동기화 — 그래서 내 기록은 이 브라우저에만 남는다
- 사진 업로드 (영상만 받는다)
- 암장 공식 데이터 연동 — 암장마다 색 순서가 달라, 공통 눈금 + 암장 이름 병기로 대신함
- 게시판 댓글, 좋아요, 글 수정·삭제 (로그인이 없어 남의 글을 지울 수 있게 된다)
- 영상 업로드 속도 제한 — 주소가 알려지면 저장소를 채울 수 있다는 건 남은 약점이다
