# 증빙 화면 촬영 목록

아래 이름으로 이 폴더에 넣고 `짤카드 보고서 생성.py`를 다시 실행하면 보고서 부록이 자동으로 채워집니다.
파일명은 앞의 번호만 맞으면 되고 뒤에 글자를 더 붙여도 됩니다. (예: `09_결함_수정전_표캡처.png`)

```bash
python "짤카드 보고서 생성.py"
```

## A. 편집과 미리보기 (카드 1)

| 파일명 | 무엇을 찍나요 |

| `01_PNG불러오기.png` | PNG를 불러온 편집 화면. 파일 이름과 미리보기가 함께 보이게 |
| `02_JPEG불러오기.png` | JPEG를 불러온 편집 화면 |
| `03_문구변경.png` | 문구 내용·위치·크기·색을 바꿔 미리보기가 달라진 화면 |
| `04_지원안하는파일.png` | SVG나 GIF를 넣어 거부 사유가 뜨고 **기존 편집 내용이 그대로 남아 있는** 화면 |
